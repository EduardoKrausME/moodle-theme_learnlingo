# Changelog

This changelog records verified changes in published GitHub releases. Each entry compares the release tag with the immediately preceding published release; changes made after the tag are excluded. Earlier releases are available in GitHub's release history.

## 2.2.1 - 2026-11-16

- Improved export of public theme colors and the configured Moodle logo to mobile application builders, with validation against the stored logo file.
- Added a public mobile branding endpoint and regression coverage for branding.
- Adjusted navbar, drawer control and page layout SCSS.

**Comparison:** [2.2.0...2.2.1](https://github.com/EduardoKrausME/moodle-theme_learnlingo/compare/2.2.0...2.2.1)

## 2.2.0 - 2026-11-15

- Removed the standalone visual editor and obsolete editor references while retaining MCP-related links.
- Exposed LearnLingo brand colors and navbar tokens to Kopere Mobile.
- Updated mobile branding tests and Moodle coding-standard compatibility.

**Comparison:** [2.1.1...2.2.0](https://github.com/EduardoKrausME/moodle-theme_learnlingo/compare/2.1.1...2.2.0)

## 2.1.1 - 2026-11-14

- Moved visual editor asset listing and deletion to Moodle external services.
- Fixed dark-mode homepage color-scheme inheritance and aligned the generated JavaScript asset and PHP tests.
- Added third-party library attribution, localized footer text and PHP file headers.

**Comparison:** [2.1.0...2.1.1](https://github.com/EduardoKrausME/moodle-theme_learnlingo/compare/2.1.0...2.1.1)

## 2.1.0 - 2026-11-14

- Added content editor guidance to page forms and improved branding JSON administration styling.

- Revised bundled fonts and associated theme styles.
