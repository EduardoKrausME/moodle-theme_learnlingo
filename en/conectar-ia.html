How does this connection work?

LearnLingo controls your Moodle site's presentation. The optional Moodle MCP plugin allows an AI assistant to interact with authorized Moodle operations under your user's permissions.

LearnLingo: your visual identity

Customize colors, logos, homepage, course layout, footer, and login experience. Settings remain stored in Moodle.

Moodle MCP: the optional connector

Installed separately, it exposes authorized Moodle operations to ChatGPT or Claude. MCP is simply the protocol used for this connection.

ChatGPT or Claude: the conversation

Describe what you need, review suggestions, correct details, and approve the allowed changes. AI does not replace administrative review.

Connect in six steps

Start with a test environment, an administrator account, and a Moodle installation accessible over HTTPS. The connection menus depend on your account and the current application.

1

1. Install LearnLingo

Install and activate the theme. If you haven't done this, follow the installation guide and set up your initial branding.

2

2. Install the integration plugin

Get Moodle MCP from GitHub, install it as a local Moodle plugin, and complete the site update.

3

3. Open Connections in Moodle

Open the integration plugin's Connections page in site administration. It displays the specific information to link your Moodle site to an AI assistant.

4

4. Add the connection in ChatGPT or Claude

In your chosen service, find the option to add a compatible custom MCP connection and follow the instructions shown by your Moodle site. Availability and menu names depend on the service and your account.

5

5. Authorize your Moodle account

Sign in when requested, review the permissions, and approve only the access you need. Never paste passwords or access tokens into a chat.

6

6. Test read access first

Ask the assistant to identify your active theme or read available settings. Then request a small design change, review the preview, and approve only if it looks correct.

What should I ask ChatGPT or Claude?

You do not need to know HTML or SCSS to start. Describe the institution and request a proposal before anything is published.

Connect to my Moodle and review the current LearnLingo settings. I want a homepage for a language school, using blue as the main color, featured courses, and a welcoming message. Preserve unrelated settings, show me exactly what you would change, and request my approval before publishing.
Important: If a specific setting or action is not available through the integration, the assistant cannot perform it automatically. You can use the copy-and-paste method to prepare a JSON configuration instead.

Permissions and approvals

Connecting Moodle does not grant an AI assistant unrestricted access. The connection must be authorized, and each operation is restricted by available permissions.

Read before writing

Ask the assistant to inspect existing settings and preserve any fields unrelated to your request.

Review before publishing

Check text, colors, contrast, links, and mobile behavior. Administrative changes require the approval supported by the integration.

Use the least privilege needed

Use the minimum access necessary and review any personal or institutional information before sharing it with an external service.

If the connection doesn't work

Most connection failures are caused by account availability, configuration, or authorization rather than the LearnLingo theme itself.

The connection option is missing in ChatGPT or Claude.

Check that your account and application support custom connections. Follow the current service instructions and Moodle's Connections page.

Moodle authorization fails.

Check HTTPS, account permissions, plugin configuration, and your server's authentication requirements. Ask your administrator to review the server configuration if needed.

The assistant can read but cannot edit.

Write operations may be disabled, unavailable, or blocked by Moodle account permissions. Do not bypass these controls.

I installed a new feature but it is not listed.

Make sure the compatible plugin is enabled and refresh the connection or available tools in the assistant.

Do I need this integration to use LearnLingo?

No. The theme works without it. The copy-and-paste guide explains an alternative.
