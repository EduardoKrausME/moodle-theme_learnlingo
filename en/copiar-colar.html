FROM FIRST CLICK TO PUBLICATION

Five steps. No complications.

Everything starts and finishes in Moodle, using features already available in LearnLingo.

01

Open the LearnLingo exporter

Sign in as an administrator and open the theme settings under Site administration → Appearance → Themes → LearnLingo. Find the option to export a ChatGPT prompt and import JSON.

You can also open this path on your own Moodle site:

/theme/learnlingo/admin/branding_json.php
02

Copy the complete prompt

In the export section, select Copy prompt. The text already includes your current LearnLingo settings and instructions for AI to ask questions before proposing changes. You do not have to build JSON manually.

The "Current JSON" field is available on the same page as a reference or backup before importing changes.

03

Chat with ChatGPT or Claude

Paste the complete prompt into a chat and explain what you want: colors, branding, home page, footer, login text, or course appearance. AI can clarify your preferences and prepare a proposal.

The example below can be sent as an additional message after the exported prompt; adapt it for your institution.

Example request

I want to customize LearnLingo for a school offering short courses. I prefer blue and green branding, a modern home page highlighting courses, and an institutional footer. Ask any questions you need, and preserve every setting I have not requested to change. Before generating the final JSON, summarize the proposed changes for my approval.

04

Review the JSON returned by AI

Once the proposal is ready, ask for the complete importable JSON, keeping the original structure and all fields. Carefully review text, HTML, colors, and SCSS, as these may affect other pages.

When importing, paste only the JSON object: no ```jsonfences, comments, or text before or after. The importer validates everything before saving.

05

Import and check in Moodle

Return to the same LearnLingo page, paste the result into the import field, and select Import settings. The changes are only applied at this point, and the theme clears its caches after importing.

Check the home page as a visitor and a student, open a course, and review the login, footer, mobile navigation, and dark mode when available.

BEFORE YOU BEGIN

What does this method change?

This exchanges settings rather than giving remote access to Moodle. ChatGPT or Claude prepares a file, but the administrator decides whether to apply it.

What JSON can customize

Colors, text, home-page HTML, SCSS styles, footer, course presentation, and theme options.

Some settings stay in Moodle

Logos, favicon, and uploaded images must be configured separately. JSON does not include these files.

Keep a backup

Before importing, save a copy of the current JSON, because importing replaces the settings in the document.

QUESTIONS THAT COME UP IN PRACTICE

Good to know before applying.

The copy-and-paste workflow works independently of a direct connection between AI and Moodle.

Do I need a ChatGPT or Claude connection plugin?+

No. All you need to copy the prompt and import JSON is the LearnLingo theme and administrator access. The integration plugin is optional and enables working directly from a conversation.

Does ChatGPT change my Moodle automatically?+

Not with this method. You receive a JSON proposal and apply it only after pasting the content into the import page and confirming the operation in Moodle.

Can I use a logo created by AI?+

Yes, but image files are not part of the JSON. Save the logo and upload it through the branding or login settings, depending on where you plan to use it.

What if the importer rejects the JSON?+

Make sure the answer contains only complete JSON without Markdown fences. Ask AI to keep the same keys, identifiers, and types as the original, preserving fields you want unchanged. No settings are saved if validation fails.

Can I put any institutional information in the prompt?+

The prompt includes existing text and settings, which may contain institutional content. Review what you share before pasting into external services and avoid unnecessary personal or restricted data.
