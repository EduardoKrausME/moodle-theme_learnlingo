Give Moodle a fresh look.

LearnLingo is a free, open-source theme built on Boost. Install it on your Moodle site, enable it as the site theme, and customize branding, homepage, course layouts, and login without replacing courses or activities.

Download latest releaseRead installation instructions first

Your new Moodle design in three stages

1Check requirements and create a backup.
2Install the theme and finish the Moodle site update.
3Activate LearnLingo and customize your institution.

What do you need?

Test in a staging environment before changing the appearance of your production Moodle site.

Moodle 4.5 or later

Repository release 1.5.12 declares Moodle 4.5 as the minimum supported version. Check the exact release requirements before updating.

The Boost theme

LearnLingo depends on Boost, included with compatible Moodle installations. Moodle courses, grades, and enrolments continue to work as usual.

Administrator access

You need permission to install plugins, complete site updates, and select a site theme. Back up code, database, and files before production changes.

Image customization

You can add your logo, favicon, and institutional imagery. Some image resizing operations use the PHP GD extension on the server.

How to install LearnLingo

You can upload the ZIP through Moodle administration or place the extracted theme on the server. Choose one of these methods.

1

1. Download the theme

Open the latest GitHub release and download a package compatible with your Moodle version.

2

2. Install via Moodle or your server

Use Moodle's plugin installer to upload the ZIP if available. Alternatively, extract the theme into theme/learnlingo inside your Moodle directory. Avoid extra parent folders introduced by ZIP extraction.

3

3. Complete the Moodle update

Sign in as an administrator and open Site administration → Notifications to finish any installation and upgrade steps.

4

4. Enable the theme

Go to Site administration → Appearance → Theme selector and choose LearnLingo for the relevant context. Installing a theme does not necessarily activate it.

5

5. Customize your branding

Open LearnLingo settings or its visual setup wizard when available. Configure colors, logo, favicon, homepage, footer, learner pages, and login.

6

6. Test before publishing

Check homepage, a course page, login, and learner navigation on desktop and mobile. Verify contrast, links, images, progress, and menus before rolling out.

What can you customize?

LearnLingo keeps Moodle's educational features intact while offering more control over the institution's appearance.

Brand and colors

Apply institutional colors, logos, and favicon without editing the theme source.

Homepage and courses

Choose the homepage layout, feature courses, refine course headers, and use HTML or SCSS when appropriate.

Login and footer

Personalize login, learner navigation, and institutional footer content.

Optional AI assistance

Connect ChatGPT or Claude to Moodle for conversational changes, or copy your settings into a chat and manually import the reviewed JSON.

Frequently asked questions

A few checks now can prevent problems that only appear after the theme reaches production.

Is LearnLingo free to use?

Yes. It is published under GPL v3 or later, subject to the license conditions.

Does LearnLingo change my courses or grades?

The theme changes visual presentation. Moodle still manages courses, activities, grades, and enrolments.

The theme does not appear in Theme selector.

Check the folder structure, complete the installation under Notifications, and verify Moodle compatibility.

The site looks different than expected.

Purge Moodle caches, review the theme settings, and test in a private browsing window. Check any custom SCSS overrides.

Should I enable it directly in production?

Test first on a staging copy and keep a rollback plan, especially if your installation uses other plugins or customizations.

Is ChatGPT or Claude required?

No. Administration can be done manually, and the AI integration is optional.
